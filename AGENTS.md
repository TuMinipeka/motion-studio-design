# Trabajo en este repositorio

- Usa Conventional Commits: `tipo(alcance): descripción`, con mensajes claros y cambios agrupados por propósito. Consulta `CONTRIBUTING.md`.
- Documenta cada mejora de comportamiento en `CHANGELOG.md` en el mismo commit. Actualiza README y referencias cuando cambie el uso de la skill.
- Explica problema, cambio, validación y límites. Distingue código implementado, pruebas realizadas y trabajo pendiente; las métricas de movimiento no garantizan calidad artística.
- Conserva el trabajo ajeno y no reescribas commits publicados para corregir su estilo.
- Mantén las autorizaciones de producción de video de `motion-studio/SKILL.md`; una tarea de documentación o commits no autoriza producir un video del usuario.
